# Missa Tradicional Portugal

Site em Vite + React + TypeScript + Tailwind v4.

- `npm install` e depois `npm run dev` para desenvolver
- `npm run build` gera a pasta `dist`
- Todo o texto está em `src/content.ts`

Vercel: importar o repositório do GitHub. Framework Vite, build `npm run build`, output `dist`.
